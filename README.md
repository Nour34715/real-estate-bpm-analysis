# Real Estate Business Process Modelling (BPMN)

## Overview

This project focuses on Business Process Management (BPM) and workflow modelling for the real estate industry using Business Process Model and Notation (BPMN).

The project redesigns and analyses real estate workflows by transforming an existing flowchart into a professional To-Be BPMN model that demonstrates actors, entities, pools, swim-lanes, process flows, time cycles, and cost considerations involved in property purchasing and rental operations.

## Project Components

### To-Be BPMN Model

Designed a To-Be business process model based on an existing real estate workflow diagram.

### Workflow and Actor Analysis

Analysed interactions between:

* Property owners
* Real estate agents
* Brokers
* Conveyancers
* Purchasers
* Tenants
* Local councils

### Rental and Purchase Workflow Design

Modelled the processes involved in:

* Purchasing properties
* Renting properties
* Approval and documentation workflows
* Time and cost cycles

### Process Documentation

Provided analytical discussion and justification for:

* workflow structure
* modelling choices
* process parameters
* operational assumptions
